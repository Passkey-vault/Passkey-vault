01 // OVERVIEW

Executive Summary & Architecture

The passkeyvault-core reference implementation delivers institutional-grade keyless account abstraction on Stellar, bridging hardware biometrics (Face ID, Touch ID, Windows Hello, and YubiKeys) directly to Soroban smart contracts. By leveraging the Protocol 21 native host syscall for secp256r1, the contract removes the requirement for slow, expensive WASM-level elliptic curve curve computations.

key_off

Zero Seed Phrases

Keys remain isolated inside device secure chips. Users authorize transactions using WebAuthn without exposing raw private keys to memory or browser storage.

local_gas_station

Zero-Gas UX Paymasters

Native compatibility with Stellar fee-bump transactions allows dApps or sponsoring guardians to subsidize resource fees seamlessly without friction.

group_work

M-of-N Quorum Recovery

Social guardians with time-locked thresholds ensure non-custodial wallet recovery in the event of hardware loss or broken device enrollment.

#[contractimpl]
impl PasskeyVault {
    pub fn verify_and_execute(
        env: Env,
        signature: BytesN<64>,
        client_data_hash: BytesN<32>,
        action: VaultAction,
    ) -> Result<Val, VaultError> {
        // Load stored public key from instance storage
        let state: VaultState = env.storage().instance().get(&DataKey::VaultState).unwrap();
        
        // Protocol 21 Native Host Syscall: 0.12ms execution
        env.crypto().secp256r1_verify(&client_data_hash, &signature, &state.secp256r1_pubkey);
        
        // Extend state TTL automatically (+31 days)
        env.storage().instance().extend_ttl(535_679, 535_679);
        Self::dispatch(env, action)
    }
}
// TypeScript / WebAuthn Hardware Assertion Dispatch
